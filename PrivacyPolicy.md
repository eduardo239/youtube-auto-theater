# Privacy Policy — YouTube Auto Theater

**Last updated:** August 26, 2026  
**Developer:** eduardo239  

YouTube Auto Theater is a browser extension that automatically enables YouTube theater mode and collapses live chat on watch pages.

## Data we collect

We do **not** collect, store, or transmit any user data.

The extension does not collect personally identifiable information, health data, financial data, authentication credentials, personal communications, location, web history, user activity, or website content.

It does not use analytics, advertising, cookies, or any of our own servers.

## How the extension works

The extension runs a local content script only on `https://www.youtube.com/*`. On a watch page, it inspects the player interface in that tab (for example, whether theater mode is on and whether live chat is visible) and clicks YouTube’s own theater and chat controls.

This happens entirely on your device. Page information is used only in memory to provide that feature and is not saved or sent anywhere.

## Sharing and sale of data

We do not sell user data. We do not transfer user data to third parties. We do not use user data for advertising, credit scoring, or any purpose other than the extension’s single function.

## Limited use

This extension complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Because no user data is collected, none is used, transferred, or retained.

## Changes

If this policy changes, we will update this page and the “Last updated” date. If a future version of the extension starts collecting data, we will update this policy and the Chrome Web Store privacy disclosures before that version is published.
